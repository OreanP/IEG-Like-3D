# Références techniques consultées pour le portage

- Manettes, actions, zone morte : https://docs.godotengine.org/en/stable/tutorials/inputs/controllers_gamepads_joysticks.html

Les scripts, scènes, matériaux et modèles de ce lot constituent le code du
prototype, pas des assets officiels Inazuma Eleven. Les deux GLB proviennent de
l'archive de projet S0 fournie précédemment ; ils y ont été générés pour le projet.
Aucun pack Kenney, Quaternius ou modèle extrait d'un jeu commercial n'est inclus.
